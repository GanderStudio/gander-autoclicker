# Gander AutoClicker

Gander AutoClicker is a lightweight desktop autoclicker developed by **Gander Studio**.

The project currently focuses on Linux and uses a PySide6 interface with a direct Linux input backend. The goal is to keep the application simple, responsive, and low on resource usage while gradually expanding it into a cross-platform tool.

## Current status

Early development.

The Linux version currently supports:

- Configurable clicks per second
- Left, right, and middle mouse buttons
- Start/Stop controls
- Configurable local hotkey
- Direct Linux mouse input

## Future plans

- Add native support for Linux, Windows, and macOS
- Improve the clicking backend for better efficiency and timing consistency
- Build a cleaner and more polished user interface
